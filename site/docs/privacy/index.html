    Anonymous usage counts

    What A9 Voice counts, what it is, what never leaves your PC, and how to turn it off or reset it.

    Last updated for A9 Voice 1.0.26

    A9 Voice counts installs so we know whether anyone is using it, which version they are on, and whether people get through setup and use it. The count is anonymous: there is no account to tie it to, and it carries nothing you said, wrote or recorded. It is on by default and you can turn it off in Settings › Privacy.

    What is counted#

    When A9 Voice checks for an update, the request to a9voice.com carries a random ID, the app version, your update channel (Stable or Dev), your Windows version (for example "Windows 11, build 26200") and your PC's processor type. a9voice.com adds your country, worked out from the request. The ID is a random number made on your PC the first time A9 Voice ran. It is not made from your name, your PC or your account, and it cannot be turned back into any of them. A brand-new install also sends one extra message the first time it starts, so we can tell a real install from a download that was never opened. Installers downloaded from a9voice.com carry a random code in the file name. The app sends it once with the first-launch count so we know which link the download came from. It isn't tied to you. If you installed A9 Voice from the Microsoft Store, that same first message says so ("store"), so we can count Store installs; it carries nothing else. A Store copy that runs as a Microsoft Store package sends none of these counts: the Store counts its installs and updates it.

    Five more messages are sent once each, with the same ID and the same fields and nothing else: when you finish setup with a way to transcribe that works, when you make your first dictation, when you record your first note, when you start the Notes trial and when you buy Notes (a complimentary key sends nothing). They tell us whether people get through setup and use the app: never what you said or recorded. An install that was already past one of these steps when it updated to the version that counts it does not send it, and with the switch off none of them is sent.

    We do not store your IP address, and the website sets no cookies. The site counts three things so we can see which places bring people: a visit (one anonymous message per browser tab, with the website the visitor came from, the first page and the kind of device, such as Windows or phone), a view of the download page, and a click on its download button, each with the link it came from (a post, a profile, a listing) and the button that was used. Nothing is kept on your device beyond that tab's memory, and nothing identifies you. On a phone, the download button says Send it to my PC: when you email, share or copy the link, that counts one more message with the same link and button fields, and a view of the download page counts once each time it loads in a browser. If you ask us to email you the download link from your phone, we send that one email and don't keep your address. To stop abuse we keep a one-way fingerprint of that address and of your IP address for 24 hours, then delete it; the address itself is never stored. The pages themselves are also counted by Cloudflare's cookieless Web Analytics: page views and where visitors came from, with no cookie and no profile of you.

    The Notes trial and license are separate#

    The count above has a switch. The Notes trial and license checks do not, because Notes cannot tell whether your 30 days are used up without asking. They are not part of the usage count and use a different request to a9voice.com. The count only learns, once each, that a trial started or a license was bought, and that message follows the switch.

    • Your PC's code. When you open Notes, A9 Voice sends a code made from your PC, so a reinstall finds the trial you already have; nothing is stored until you press Try Notes free, which starts the 30 days, and the code is kept with them. If you buy, the same code is what lets this PC unlock itself once the payment goes through; it never carries your key to anyone else. The code is a one-way hash of the Windows machine ID with a fixed value mixed in. The machine ID itself never leaves your PC, and the code cannot be turned back into it or into you. It is what lets a reinstall on the same PC keep the same 30 days. Dictating with Transcribe never sends it.
    • Your email, only if you ask for 14 more days. We keep it with that PC's code, to send you the 6-digit code and to answer you. Product updates only if you tick the box.
    • A purchase. Checkout is Stripe's page in your browser. A9 Voice and a9voice.com never see your card. We keep the order record (email, amount, date), your key and which PCs use it. A license key is checked with a9voice.com about once a day.
    • The recording-consent notice's version. When Notes starts, A9 Voice shows a short notice about getting consent before you record other people (see Recording consent). The Notes trial start, and the next trial or license check if you pressed Got it later, carries one flag with it: consent_v, the version number of that notice, such as 1. a9voice.com stores the number with the time it arrived, on the same trial or license record. It is a number and nothing else: no name, no email, no content. It rides on a check A9 Voice already makes, never as a request of its own, and it is never sent back to the app.
    • What never goes with it. Audio, text, names, notes, file names, your keys and your settings.

    Problem reports are separate#

    Report a problem (the About card at the bottom of Settings › General, or the tray menu under Help) is not part of the count and has no switch, because it does nothing until you press Send. A report holds what you typed in the two boxes, the email address if you gave one, and, if you leave Include diagnostics on, the text under Show what's sent: the version, update channel, Windows version, the type of microphone, a summary of switches and engine names, display and graphics-card details, and the last 200 lines of the log. Keys, the Windows user folder, people's names, note titles, recent dictations and email addresses are taken out first, and it never holds audio, transcripts, summaries, voiceprints or file paths under your profile. The report also carries a code made from your PC (the same one-way hash the Notes trial uses) that only limits reports to five a day.

    It goes to a9voice.com (or its mirror a9voice.atlas9.ai when a network blocks the first), is stored with a report ID, and is mailed to support@a9voice.com. We use it to find and fix the problem and to reply if you gave an address. Reports are deleted after 180 days. A report that could not be sent stays in the app's data folder, in reports-pending.json, and is sent at the next update check for up to 14 days; delete the file to discard it.

    What never leaves your PC#

    Audio, dictated or transcribed text, notes, names, voiceprints, file names and paths, your API keys and your settings never go with the count. (A problem report you choose to send is a different thing; see above.) Audio and text go only to the speech and language services you set up yourself; see Privacy and data for every place.

    Turn it off#

    1. Open Settings › Privacy.
    2. Switch Send anonymous usage counts off.

    With the switch off, the update check sends no ID and nothing about your PC, and neither the first-start message (with its download code, which is then deleted) nor the five milestones are sent. a9voice.com records nothing at all for those requests. Updates work the same.

    The switch is for the app. It does not affect what the website counts about a visit to a9voice.com, which has no ID and no cookie.

    If your network blocks a9voice.com, A9 Voice sends the same requests (the update check, the Notes trial and license checks, the counts when the switch is on) to a9voice.atlas9.ai, a mirror of the same server, and remembers which one answered. It sends nothing more and nothing different.

    Reset the ID#

    Reset ID in Settings › Privacy makes a new random ID. The old one is forgotten on this PC, and nothing links the old and the new. An exported settings file never contains the ID or the milestones, so importing it on another PC does not copy them.
