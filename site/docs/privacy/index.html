    Anonymous usage counts

    The one thing A9 Voice counts, what it is, what never leaves your PC, and how to turn it off or reset it.

    Last updated for A9 Voice 0.6.6

    A9 Voice counts installs so we know whether anyone is using it and which version they are on. The count is anonymous: there is no account to tie it to, and it carries nothing you said, wrote or recorded. It is on by default and you can turn it off in Settings › Privacy.

    What is counted#

    When A9 Voice checks for an update, the request to a9voice.com carries a random ID, the app version, your update channel (Stable or Dev), your Windows version (for example "Windows 11, build 26200") and your PC's processor type. a9voice.com adds your country, worked out from the request. The ID is a random number made on your PC the first time A9 Voice ran. It is not made from your name, your PC or your account, and it cannot be turned back into any of them. A brand-new install also sends one extra message the first time it starts, so we can tell a real install from a download that was never opened.

    We do not store your IP address, and the website sets no cookies. The download button on this site counts a download and the link it came from (a post, a profile, a listing) so we can see which places bring people. The pages themselves are counted by Cloudflare's cookieless Web Analytics: page views and where visitors came from, with no cookie and no profile of you.

    What never leaves your PC#

    Audio, dictated or transcribed text, notes, names, voiceprints, file names and paths, your API keys and your settings never go with the count. Audio and text go only to the speech and language services you set up yourself; see Privacy and data for every place.

    Turn it off#

    1. Open Settings › Privacy.
    2. Switch Send anonymous usage counts off.

    With the switch off, the update check sends no ID and nothing about your PC, and the first-start message is never sent. a9voice.com records nothing at all for that request. Updates work the same.

    Reset the ID#

    Settings › Privacy › Reset ID makes a new random ID. The old one is forgotten on this PC, and nothing links the old and the new. An exported settings file never contains the ID, so importing it on another PC does not copy it.
