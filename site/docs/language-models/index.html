    Language models

    Add the AI models that write your meeting summaries, answer Ask, and tidy your dictation with Enhance with AI. Use a cloud key or a model on your own PC.

    Last updated for A9 Voice 0.7.24

    A language model reads text and writes text. Speech models turn your voice into words; language models do things with the words:

    • Summaries: after a meeting, one request writes the summary, a title and tags for the note.
    • Ask: answers your questions about one note, about the call you are in right now, or across all your notes.
    • Enhance with AI: tidies each dictation before it is typed: removes “um” and “uh”, fixes punctuation and capitals.

    None of this is required. Dictation and recording work without a language model; you just don't get summaries, Ask or Enhance.

    Keys live in Settings › Models, under Providers and keys › LANGUAGE MODELS. Which model does which job is chosen at the top, under What each job uses (see Models).

    The speech engines are on that page too. To see how to choose them for dictation and notes:

    Set up a provider#

    The app offers five: OpenRouter, OpenAI, Anthropic, Groq and Google. The steps are the same for each. Your key goes into Windows Credential Manager, never into a file, a log or the app's storage.

    1. Open Settings › Models, scroll to Providers and keys and click the provider's tile.
    2. Click the big blue Get your OpenRouter key → button (the name changes with the provider). Your browser opens the provider's key page.
    3. There, sign in, create an API key, and copy it. Back in A9 Voice the cursor is already in the key box.
    4. Paste it into API key.
    5. Check the Model. It is the provider's default for jobs that don't name one. It is a box you can type in; the list offers the provider's usual choices, and you can enter any model name the provider knows.
    6. Click Test. A9 Voice sends a short phrase full of fillers (“um so uh the release is on uh Thursday you know”) and shows the cleaned-up answer and the time, for example “So the release is on Thursday.” · 0.64 s. Nothing is saved yet.
    7. Click Save. Then choose where to use it with Change on a job under What each job uses.

    The strip under the big button, Get a key, Paste it here, Test, ticks as you go.

    A key you already added#

    Groq and OpenAI use the same key for speech and for language models. If you set one up under the speech services, its tile here already shows the gear instead of Add key, and its window shows Key saved.

    To change a key, open the tile, click Manage key, paste the new one and Save. Disconnect deletes the saved key (for Groq and OpenAI that removes it for speech too); a job that used that provider goes back to Same as Summaries, and Summaries to Automatic.

    Choose which model does what#

    Each job has its own row under What each job uses in Models: Summaries, Ask: Quick, Ask: Deep and Enhance. Change opens a searchable list of every model your providers offer, with its context window and price. Ask: Deep also shows what one answer costs.

    Summaries and titles#

    Summaries picks the model that writes the summary, title and tags. The other three follow it unless you give them their own. Leave it on Automatic and A9 Voice uses the first one you have set up, in this order: OpenRouter (the newest Claude Haiku, Claude Haiku 5.5 today), Anthropic (the same), OpenAI (GPT-4.1 mini), Groq. Groq comes last because a long meeting can be more than a free Groq key allows per minute. Any other model you set up, including your own server, is tried after those.

    The Summary model row in Settings › Transcript & summary is the same choice.

    Long meetings#

    Some models take only so much text in one request. Groq's free tier, for example, allows its GPT-OSS models 8,000 tokens a minute, which is less than a 30-minute meeting. When a meeting is more than the Summary model takes at once, A9 Voice writes it in parts: it reads the transcript a part at a time, never cutting a turn in two, keeps short notes on each part, then puts the notes together into the same summary, title, tags and action items as any other. The finished summary looks the same. Where Groq's per-minute limit asks for it, A9 Voice waits for the minute to pass, so a long meeting takes a few minutes longer. While it works the note says Writing summary… part 2 of 4, and waiting for Groq's per-minute limit when it is waiting.

    You can have it the other way. Settings › Transcript & summary › Long meetings has two choices:

    • Chunk on the same model (the default): the Summary model writes the meeting in parts.
    • Use fallback model: when another model you have set up takes the whole meeting in one request, it writes the summary instead, and the Summary model is tried after it.

    With Groq as the only language model, Settings › Models says under Summaries that long meetings are handled in parts and take a bit longer. Another provider's key makes them single-pass.

    A meeting that failed before with request too large for Groq's per-minute token cap on this model in the last 30 days is summarized again by itself the first time you open this version, oldest first, one at a time. Nothing needs a click.

    If it still can't be done, the note names the limit and when it resets, for example Groq's daily token limit for this model is used up; resets in 3 h. Try another model or try again later.

    Ask#

    Ask: Quick and Ask: Deep each take their own model, or Same as Summaries. Deep reads more passages, so a stronger model is worth it; the list marks models that are Good for Deep. Ask: Quick also thinks of the extra search words for a Deep answer.

    Enhance#

    Enhance follows Summaries until you pick a model for it, here or under Settings › Dictation › Enhance with AI › Model. A small, fast model keeps dictation quick.

    The AI chip#

    The AI: chip at the top of every window shows the model Summaries use now. Click it to switch: Automatic (with the model it would pick) or one of your set-up models. When Enhance or Ask uses a different model, the chip says +1 override. Settings… opens the Models page.

    When a model recently failed or hit a limit, the chip shows an amber dot for 10 minutes. The menu says what happened and who answered instead, for example OpenRouter rate limit (429) 2 min ago. Anthropic · Claude Haiku 4.5 answered instead.

    When a model fails#

    For summaries and Ask, if the chosen model is rate-limited, takes too long, can't take a request that big, or the provider has an error or rejects the key, A9 Voice tries the next model you have set up, one per provider, in the order above. The footer says why: after: Groq rate limit (429) or after: request too large for Groq's per-minute token cap on this model. A request known not to fit is skipped without being sent. With no internet it stops, because the next one would fail the same way.

    So the most reliable setup is two providers with keys. Enhance is different: it uses only its own model and has a short time limit. If it can't answer in time, you get the text as heard (see below).

    Enhance with AI#

    Enhance tidies each dictation before it is typed. It is off until you turn it on, in Settings › Dictation, under Enhance with AI.

    • Enhance with AI: the switch. It removes “um” and “uh”, fixes punctuation and capitals, and spells your Dictionary words right.
    • Model: the model that does it. Same as Summaries is the default. If no model is set up, the row says Add a key in Settings › Models first. Until then, text is pasted as heard.
    • Style: Light cleanup or Formal. Formal only adjusts the tone a little: it can expand contractions and swap very casual words for neutral ones. It never adds content.
    • Wait at most: 1.0 s, 1.5 s (the starting value), 2.0 s or 3.0 s. Past this, the raw text is pasted so dictation never stalls.
    • Custom instructions: your own rules, for example how a name should be spelled. They can't override the rules below.

    What it never does#

    It never rewrites, shortens, reorders, summarizes, translates or answers what you said. If you dictate a question, you get the question, tidied, not an answer. What you dictated is treated as text to edit, never as instructions.

    When it is skipped#

    Dictation never fails because of Enhance. When Enhance is too slow, fails, or returns something that doesn't look like a cleanup (much longer or shorter than what you said), the text is pasted as heard. In Transcribe, the item shows AI too slow · as heard, AI failed · as heard or AI reply skipped · as heard, and a good one shows AI with the time. A link on each item switches between Show original and Show enhanced.

    Enhance sends the text of each dictation to the model's provider. Pick a model on your own PC if that matters; see below.

    3. Paste the key into API key. Don't have one?     4. Look at Model. A moment after the key is in, it becomes a list of that service's chat models, with a small, cheap one already chosen. Pick another if you like. Refresh list asks again; Type a name… at the end of the list lets you enter one the list lacks. If the list can't be loaded, Model stays a box you type in, and one line says why.
    5. Click Test. It sends one short chat message and shows the model's answer and how long it took, for example “Hello, nice to meet you!” · 0.64 s. Nothing is saved yet.
    6. Click Save. Then choose where to use it with Change on a job under What each job uses.

    When something is wrong#

    Test and the model list say what happened in plain words:

    • Local server not running: nothing answers at localhost:11434. Start Ollama on this PC, then try again. The program isn't running, or it is on another port.
    • … needs an API key or … rejected the key: paste the key again, whole, from the service you picked.
    • Nothing answers at this address (404). The Base URL looks wrong; it usually ends in /v1. The address is not the service's.
    • … doesn't have a model called "…": pick one from the list.
    • … says you're over its rate limit (429), … took too long to answer or … had a problem (error 500): the service is busy; try again in a minute.

    Advanced#

    Advanced is closed to begin with. For a service from the list it holds Name, Base URL (the filled-in address, which you can change), Extra header (optional) and Header value. The line under them says: Only needed for company servers that ask for an extra ID. Leave them alone unless your company's server asks for one; the header's value is stored like a key, in Windows Credential Manager.

    The line about your data#

    Some services' own terms say something you may want to know before you paste a key. When they do, one neutral sentence shows in the window and on the tile: Google's free tier, DeepSeek and Mistral's free plan, as in the table above and under Providers and key pages. Where a service's terms say it doesn't train on what you send and process it nowhere unusual, no line is shown. The sentence comes from the service's terms as of this version; the terms themselves are the authority, and they can change.

    Your own server (Other)#

    Other (OpenAI-compatible) is the form this window had before: Name, Base URL such as http://localhost:8000/v1, API key (optional), Model, and under Advanced the extra header. Servers added before presets existed open this way, unchanged.

    Use a model on your own PC#

    Programs that run language models on your computer and speak the OpenAI chat format connect through Add custom API too. Ollama and LM Studio are in the list: start the program, make sure it has a model, then pick Ollama (on this PC) or LM Studio (on this PC). There is no key, and the Model list is what is installed. If the program isn't running, the window says Local server not running and what to start.

    For another local program, pick Other (OpenAI-compatible) and give its address, for example http://localhost:8000/v1.

    A9 Voice sends an ordinary chat request to your Base URL plus /chat/completions: the model name, the instructions and the text, with the key and header if you set them. Nothing else is sent, and with a server on localhost nothing leaves your PC. Your custom model also joins the Summaries order after the built-in providers. If your model is slow, remember Enhance's Wait at most limit; Test waits up to 30 seconds.

    Disconnect on a custom server removes it and its saved key and header.

    What it costs#

    A9 Voice doesn't charge for language models; you pay each provider directly with your own key. Settings › Usage & cost shows an estimate for the month, priced with a table of prices you can edit. See the settings reference.

    If something goes wrong#

    • OpenRouter key rejected (or another name): the key is wrong or expired. Open the tile, Manage key, paste a new one, Test, Save.
    • … key missing: add a key for that provider.
    • … rate limit (429) or … took too long: the provider is busy. Summaries and Ask move to the next model; Enhance pastes the text as heard.
    • request too large for … on this model: the request is bigger than that model takes (its context window, or Groq's per-minute token cap). It never counts as usage. A summary is written in parts instead (see Long meetings); Ask and Enhance go to the next model.
    • … daily token limit for this model is used up; resets in …: the provider's allowance for the day is spent. Waiting a minute won't help. On a note, Use another model opens Settings › Models; the line also says about what time of day it is back, for example resets in 3 h (around 6:40 PM). Or try again after that.
    • No internet: language models need a connection unless they run on your PC.
    • Add your OpenRouter key in Settings › Models to get summaries: no model is set up. Add a key for any provider above.
    • Test is greyed out on a custom server: it needs a Base URL, a Model and, for a service in the list, your key. The line next to it says which.
