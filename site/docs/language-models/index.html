    Language models

    Add the AI models that write your meeting summaries, answer Ask, and tidy your dictation with Enhance with AI. Use a cloud key or a model on your own PC.

    Last updated for A9 Voice 0.6.4

    A language model reads text and writes text. Speech models turn your voice into words; language models do things with the words:

    • Summaries: after a meeting, one request writes the summary, a title and tags for the note.
    • Ask: answers your questions about one note, about the call you are in right now, or across all your notes.
    • Enhance with AI: tidies each dictation before it is typed: removes “um” and “uh”, fixes punctuation and capitals.

    None of this is required. Dictation and recording work without a language model; you just don't get summaries, Ask or Enhance.

    Everything here is in Settings › Language models.

    The checkmark on a tile is the model Enhance, Summaries and Ask all use, and the AI: chip at the top of the window shows the same one. A tile with a blue Add key button has no key yet. Under the tiles, Enhance, Summaries and Ask each have a Change link for the times you want a different model for one job; a job set that way is listed there with its own model.

    Set up a provider#

    The app offers five: OpenRouter, OpenAI, Anthropic, Groq and Google. The steps are the same for each. Your key goes into Windows Credential Manager, never into a file, a log or the app's storage.

    1. Open Settings › Language models and click the provider's tile.
    2. Click the big blue Get your OpenRouter key → button (the name changes with the provider). Your browser opens the provider's key page.
    3. There, sign in, create an API key, and copy it. Back in A9 Voice the cursor is already in the key box.
    4. Paste it into API key.
    5. Check the Model. It is a box you can type in; the list offers the provider's usual choices, and you can enter any model name the provider knows.
    6. Click Test. A9 Voice sends a short phrase full of fillers (“um so uh the release is on uh Thursday you know”) and shows the cleaned-up answer and the time, for example “So the release is on Thursday.” · 0.64 s. Nothing is saved yet.
    7. Tick Use for Enhance, summaries and Ask if this is the model for everything, then click Save. The checkmark moves to the tile and the AI: chip follows at once.

    The strip under the big button, Get a key, Paste it here, Test, ticks as you go.

    A key you already added#

    Groq and OpenAI use the same key for speech and for language models. If you set one up in Speech models, its tile here already shows the gear instead of Add key, and its window shows Key saved.

    To change a key, open the tile, click Manage key, paste the new one and Save. Disconnect deletes the saved key (for Groq and OpenAI that removes it for speech too); if that model was the one in use, Enhance and Summaries go back to nothing chosen and Automatic.

    Choose which model does what#

    Pick one model with the checkmark and it does all three jobs. You can still give one job a different model.

    Enhance#

    Ticking Use for Enhance, summaries and Ask in a model's window sets Enhance too. To give Enhance a different model, pick it under Settings › Dictation › Enhance with AI › Model. This page then lists Enhance: with that model and a Change link, and the AI: chip adds +1 override.

    Summaries and titles#

    Settings › Transcript & summary › Summary model picks the model that writes the summary, title and tags, and answers Ask. It is the model the checkmark and the AI: chip show, so changing it there moves both. Leave it on Automatic and A9 Voice uses the first one you have set up, in this order: OpenRouter (Claude Haiku 4.5), Anthropic (Claude Haiku 4.5), OpenAI (GPT-4.1 mini), Groq. Groq comes last because a long meeting can be more than a free Groq key allows per minute. Any other model you set up, including your own server, is tried after those.

    Ask#

    Ask uses the same model as summaries (Same as summaries). Ask your notes also has Deep answers, which read more passages; you can give those a stronger model under Settings › Search › Model for Deep answers; this page then lists Ask (Deep answers) with it and the AI: chip adds an override.

    The AI chip#

    The AI: chip at the top of every window shows the model in use now. Click it to switch: Automatic (with the model it would pick) or one of your set-up models. This is the same pick as the checkmark: it sets Enhance, Summaries and Ask together and clears any override, and the checkmark on this page moves with it. When Enhance or Ask uses a different model, the chip says +1 override (or +2). Settings… opens this page.

    When a model recently failed or hit a limit, the chip shows an amber dot for 10 minutes. The menu says what happened and who answered instead, for example OpenRouter rate limit hit 2 min ago. Anthropic · Claude Haiku 4.5 answered instead.

    When a model fails#

    For summaries and Ask, if the chosen model is rate-limited, takes too long, or the provider has an error or rejects the key, A9 Voice tries the next model you have set up, one per provider, in the order above. You get the answer from whichever replies first. With no internet it stops, because the next one would fail the same way.

    So the most reliable setup is two providers with keys. Enhance is different: it uses only its own model and has a short time limit. If it can't answer in time, you get the text as heard (see below).

    Enhance with AI#

    Enhance tidies each dictation before it is typed. It is off until you turn it on, in Settings › Dictation, under Enhance with AI.

    • Enhance with AI: the switch. It removes “um” and “uh”, fixes punctuation and capitals, and spells your Dictionary words right.
    • Model: the model that does it. Only models you have set up are listed. If none is, the row says Add a key in Settings › Language models first. Until then, text is pasted as heard.
    • Style: Light cleanup or Formal. Formal only adjusts the tone a little: it can expand contractions and swap very casual words for neutral ones. It never adds content.
    • Wait at most: 1.0 s, 1.5 s (the starting value), 2.0 s or 3.0 s. Past this, the raw text is pasted so dictation never stalls.
    • Custom instructions: your own rules, for example how a name should be spelled. They can't override the rules below.

    What it never does#

    It never rewrites, shortens, reorders, summarizes, translates or answers what you said. If you dictate a question, you get the question, tidied, not an answer. What you dictated is treated as text to edit, never as instructions.

    When it is skipped#

    Dictation never fails because of Enhance. When Enhance is too slow, fails, or returns something that doesn't look like a cleanup (much longer or shorter than what you said), the text is pasted as heard. In Transcribe, the item shows AI too slow · as heard, AI failed · as heard or AI reply skipped · as heard, and a good one shows AI with the time. A link on each item switches between Show original and Show enhanced.

    Enhance sends the text of each dictation to the model's provider. Pick a model on your own PC if that matters; see below.

    Use a model on your own PC#

    Some programs run language models on your own computer and speak the OpenAI chat format, for example Ollama and LM Studio (the app itself suggests both). Add custom API connects to any of them.

    1. Start the program and make sure it is serving a model.
    2. In Settings › Language models, click Add custom API.
    3. Name: anything, for example Local model.
    4. Base URL: the server's address, as the program shows it, for example http://localhost:8000/v1.
    5. Model: the exact model name your server has.
    6. API key (optional): leave empty unless your server wants one.
    7. Extra header (optional) and Header value: only if your server needs one; the value is stored like a key.
    8. Click Test. It stays off until Model is filled in. Then tick Use for Enhance, summaries and Ask if you want it, and Save.

    A9 Voice sends an ordinary chat request to your Base URL plus /chat/completions: the model name, the instructions and the text, with the key and header if you set them. Nothing else is sent, and with a server on localhost nothing leaves your PC. Your custom model also joins the Summaries order after the built-in providers. If your model is slow, remember Enhance's Wait at most limit; Test waits at least 5 seconds.

    Disconnect on a custom server removes it and its saved key and header.

    What it costs#

    A9 Voice doesn't charge for language models; you pay each provider directly with your own key. Settings › Usage & cost shows an estimate for the month, priced with a table of prices you can edit. See the settings reference.

    If something goes wrong#

    • OpenRouter key rejected (or another name): the key is wrong or expired. Open the tile, Manage key, paste a new one, Test, Save.
    • … key missing: add a key for that provider.
    • … rate limit hit or … took too long: the provider is busy. Summaries and Ask move to the next model; Enhance pastes the text as heard.
    • No internet: language models need a connection unless they run on your PC.
    • Add your OpenRouter key in Settings › Language models to get summaries: no model is set up. Add a key for any provider above.
    • Test is greyed out on a custom server: fill in Model.
