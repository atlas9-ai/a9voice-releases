What Windows shows for a new publisher

Windows Defender SmartScreen shows a note for installers from publishers it hasn’t seen many downloads from yet. A9 Voice isn’t code-signed yet (that’s a paid certificate we’ll add once the project is self-funding). The note shows the publisher and file; choosing More info reveals the details and the option to continue.

Chrome and Edge can add a similar line in their downloads list for files they haven’t seen often.

To verify the file, compare its SHA-256 with the one above, or open the GitHub release. In PowerShell, Get-FileHash followed by the file name prints it.
