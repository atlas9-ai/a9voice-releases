Voice typing on Windows:
how to use Win+H, and when to use a dictation app.

Windows 10 and 11 have voice typing built in: press Win+H in a text box and talk. It needs an internet connection and a microphone. A dictation app such as A9 Voice is worth it when you want your own names spelled right, filler words cleaned up, a searchable history, or dictation that works with no internet.

STEP BY STEP

How to use voice typing (Win+H).

Click in a text box, press Win+H, wait for the “Listening...” alert, then talk. Say “Stop listening” when you’re done.

  1. Click in the text box where you want the words. Microsoft says your cursor needs to be in a text box.
  2. Press Win + H on a hardware keyboard, or press the microphone button on the touch keyboard.
  3. Wait for the “Listening...” alert, then speak.
  4. To stop, say “Stop listening”, or press the microphone button on the voice typing menu.
Source: Microsoft’s Use voice typing to talk instead of type on your PC, checked October 13, 2026. Press Win + Alt + H to move around the voice typing menu with the keyboard.

What you need

  • An internet connection. Microsoft says voice typing uses online speech recognition, powered by Azure Speech services.
  • A working microphone, and your cursor in a text box.
  • Windows 11 or Windows 10. Microsoft’s page covers both. On Windows 10 it calls the feature dictation, and Win+H opens it too.
  • A supported language. To add one, open Settings › Time & language › Language & region and select Add a language. Win+Spacebar switches between the ones you have.

Settings behind the gear icon

Select the gear icon on the voice typing menu to change:

  • Voice typing launcher: starts voice typing quickly when you’re in a text box.
  • Automatic punctuation: inserts punctuation based on what you say.
  • Filter profanity: blocks or allows typing out profanity.
  • Default microphone.
  • Wait time before acting: how long voice typing waits before it carries out a voice command.

Fluid dictation on Copilot+ PCs

On a Copilot+ PC in an English locale, Microsoft says fluid dictation corrects grammar, punctuation and filler words as you speak, using small language models on the PC. It’s on by default and you can turn it off in the voice typing settings.

It switches itself off in secure fields such as passwords and PINs. Say “Revert” or “Undo that”, or press Ctrl+Z, to get the original words back.

Source: the same Microsoft page. Its Windows 10 section says dictation needs an internet connection and that nothing needs to be downloaded or installed on Windows 10.

IF IT DOESN’T WORK

If voice typing doesn’t work.

Check that the right microphone is selected, that Windows is allowed to use it, and that the right language is on. These are the steps Microsoft documents.

What you seeWhat Microsoft says to try
Before you startOpen Start › Settings › System › Sound › Input and choose the microphone you want to use. If it’s an external microphone, check that it’s properly connected.
“Voice typing needs access to your microphone.”Open Start › Settings › Privacy & security › Microphone and make sure Microphone access is turned on.
“Voice typing isn’t available in the current language.”Check the list of supported languages and install the one you want.
Text doesn’t appear after you speakAdjust the input level of your microphone. If you’re using a built-in mic, try again with a headset or external mic.
Words aren’t entered correctlyMove somewhere quieter. Press Win+Spacebar and choose the right language. If you’re using a built-in mic, try a headset or external mic.
Source: Microsoft’s Voice typing isn’t working in Windows, which applies to Windows 11, checked October 13, 2026.
WHEN AN APP HELPS

When a dictation app is worth installing.

A9 Voice’s Transcribe is a free dictation app for Windows 10 and 11. If Win+H already does the job, keep using it. Here’s what Transcribe adds when you dictate a lot.

A dictionary for names and jargon

Optional AI cleanup

Speech models on your PC

What it asks of you

Transcribe needs a speech service: your own key from a provider you pay directly, or a model you download to your PC. Windows voice typing asks for an internet connection and a microphone. A9 Voice runs on Windows 10 and 11, 64-bit.

Questions

Is there free dictation in Windows?+

Yes. Windows 10 and 11 have voice typing built in: click in a text box and press Win+H. Microsoft’s voice typing pages list no price, and its Windows 10 text says there’s nothing to download or install. It needs an internet connection and a microphone. A9 Voice’s Transcribe is another free option, with no word limit.

How do I turn on voice typing in Windows 11?+

Click in a text box and press the Windows key + H, then wait for the “Listening...” alert and speak. To stop, say “Stop listening” or press the microphone button on the voice typing menu. The gear icon on that menu has a Voice typing launcher setting that starts voice typing when you’re in a text box.

Does Windows voice typing work offline?+

No. Microsoft’s page says you need to be connected to the internet: voice typing uses online speech recognition powered by Azure Speech services. For dictation with no internet you need an app that runs speech models on your PC, such as A9 Voice with a downloaded model.

What is the best free dictation software for Windows?+

Start with Win+H: it’s built into Windows, so you can try it right now. Choose A9 Voice’s Transcribe if you want a dictionary for names and jargon, optional filler-word cleanup, speech models that run on your PC with no internet, or a searchable history. It needs a speech service set up first: your own key, or a model you download.

Can I dictate into any app on Windows?+

Into any app where you can put the cursor in a text box. Microsoft’s page says that’s what voice typing needs. A9 Voice works the same way on one key, with one exception: Windows doesn’t let a normal app send keystrokes to a program running as administrator, so there A9 Voice copies the text and you paste it yourself.

Try it next to Win+H.

Transcribe is free. Notes is free for 30 days, then $49 once. One small installer, no admin rights needed.
